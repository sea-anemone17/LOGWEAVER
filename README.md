# ✦ LOGWEAVER Studio

코코포리아(COCOfolia)의 HTML / ZIP 채팅 로그를 **디자인된 TRPG 로그북**으로 만드는 웹앱입니다.

**웹사이트:** https://sea-anemone17.github.io/LOGWEAVER/

## 사용법

1. 코코포리아에서 HTML 로그 또는 ZIP 파일을 내보냅니다.
2. LOGWEAVER에서 **＋ 로그 불러오기**를 누르고 파일을 선택합니다.
3. **추천 디자인**에서 원하는 프리셋을 고릅니다.
4. **스타일 조정**에서 글꼴·색·레이아웃을 수정하거나 **표지 꾸미기**에서 표지 이미지·문구·장식을 편집합니다.
5. 실수로 보낸 대사를 클릭해서 **숨기기**로 제외할 수 있습니다.
6. **채팅 공개 범위**에서 공개할 탭만 선택합니다.
7. **공유용 HTML**을 다운로드합니다. 파일을 바로 전송하거나 별도 호스팅에 올려 링크로 공유할 수 있습니다.

## 현재 기능

- 코코포리아 HTML·ZIP 파싱 및 원본 타임라인 보존
- 캐릭터 아이콘·이름·색상·대사·시스템 메시지 표시
- **6종 추천 프리셋**: 클래식 북, 다크 아카이브, 모던 로그, 판타지 연대기, 로즈 가든, 포레스트
- 표지 이미지, 텍스트·장식 자유 배치(드래그), 글꼴·색상·아이콘 크기 등 설정
- 대사 수정 / 숨기기 / 복원 / 검색 / 장면 제목 추가
- 채팅 탭별 공개 여부 선택
- 브라우저 IndexedDB 자동 저장 및 JSON 프로젝트 백업·복원
- 독립형 HTML 로그북 출력 및 인쇄/PDF 저장
- 모바일·태블릿용 화면

## 비밀 채팅과 보안

- 업로드한 ZIP/HTML은 브라우저 안에서 분석합니다. LOGWEAVER가 세션 원본을 서버에 자동 업로드하지 않습니다.
- **HO, 사담, 비밀** 등으로 보이는 탭은 기본적으로 출력에서 제외하지만, 자동 감지는 완벽하지 않습니다. 공개 전 직접 확인해 주세요.
- 공유용 HTML에는 **선택한 채팅의 대사와 해당 이미지**만 들어갑니다.
- 공개 GitHub 저장소에는 **프로그램 코드만** 두고, 원본 TRPG 세션 로그나 비밀 핸드아웃을 직접 올리지 않는 것이 안전합니다.
- 자동 저장에 실패할 가능성도 있으므로 JSON 프로젝트 백업을 권장합니다.

## 범위와 향후 작업

- 디자인의 자유 배치는 현재 **표지 위의 텍스트·장식**에 적용됩니다. 본문 대사는 자동 정렬합니다.
- 링크로 자동 게시하는 기능은 아직 없으며, **다운로드한 독립형 HTML을 별도로 배포**해야 합니다.
- 내보내기 형식이 다른 코코포리아 로그는 파서 추가 지원이 필요할 수 있습니다.

## 배포

GitHub 저장소의 **Settings → Pages → Deploy from a branch → main → /(root)**를 선택합니다.

소스코드는 정적 HTML·CSS·JavaScript이며 서버가 필요하지 않습니다.
